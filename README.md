# Plataforma Doctor Fitness Assistência — MVP funcional

Projeto web estático com persistência local (localStorage), pronto para abrir em navegador.

## Funcionalidades incluídas
- Cadastro de clientes
- Cadastro de equipamentos
- Cadastro de técnicos
- Cadastro e acompanhamento de ordens de serviço
- Status e histórico de OS
- Checklist
- Peças utilizadas
- Fotos antes/depois
- Assinatura digital do técnico e cliente
- Orçamentos
- Relatórios técnicos
- Geração de PDF via impressão do navegador (Salvar como PDF)
- Dashboard operacional

## Como usar
Abra `index.html` em um navegador moderno. Os dados ficam salvos no próprio navegador.

## Próxima evolução recomendada
Migrar o armazenamento local para backend + banco de dados (ex.: Supabase/PostgreSQL), autenticação por usuário, upload em storage, geração de PDF no servidor e permissões por perfil.
